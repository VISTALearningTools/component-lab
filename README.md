# Component Lab

Component Lab is an original Classroom VISTA learning tool for practicing resistor color codes and capacitor markings. It includes Calculator, Teach, Review, and Assess modes for resistors and capacitors.

## Official version

This repository contains the protected public-distribution build used by the official GitHub Pages site. The readable development master is maintained separately and is not distributed here.
